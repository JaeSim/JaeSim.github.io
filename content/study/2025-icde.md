   - RL, Optimization

 - TopTune: Tailored Optimization for Categorical and Continuous Knobs Towards Accelerated and Improved Database Performance Tuning

   - continous knob(Gaussian Process) 과 categorical knob(Sequential Model-based Algorithm Configuration)을 개별 최적화하여 튜닝 효율 향상
   - 논문에 제안된 정보 교환 메커니즘을 통해서 각 공간을 탐색하며 의존성을 효과적으로 반영

 - Rabbit: Retrieval-Augmented Generation Enables Better Automatic Database Knob Tuning
   - knob tunning, LLM, retrieval augmented generation
   - 기존 LLM기반 knob 튜닝의 문제점 : 외부지식 통합의 한계
   - multi-agent 기반 knob 도메인 축소 기법, LLM을 surrogate model로 활용하는 탐색 전략
 
 - A-Tune-Online: Efficient and QoS-aware Online Configuration Tuning for Dynamic Workloads
   - online tunning, dynamic workload
   - 워크로드 변화를 감지하고, 재시작후 효율 저하을 방지하는 dual warm start 방식을 사용하여 QoS를 보장하는 Online Tunning 솔루션 제시
