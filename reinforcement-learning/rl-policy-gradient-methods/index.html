    7. Policy Gradient Methods #

    이전섹션에서는 action-value function(state value function, action-value function)을 근사해서 옵티멀한 value function을 찾아 갔다. 이때 policy는 \(\epsilon\) -greedy.

    policy gradient는 policy parameter를 직접 업데이트 한다. policy-based !
    policy를 direct 로 업데이트 하는것
    이는 large complicated environment에 좀더 적합() 각 state를 명확하게 구분하기 어려울때).
    Policy는 value 대비 더 compact하게 저장한다. 저게 저장하는 장점이 있긴한다.

    다음과 같은 장점이 있다고 언급한다.

    • value-based 보다 convergence가 더 잘된다는 것이 있고
    • high-dimensional 이나 contiunous action space에서 효과적이다.
      • 이경우, value-based는 심플한 직관이지만, 계산해야할 것이 많다
    • stochastic polices를 배울 수 있다.

    단점은 다음과 같다.

    • 나이브 policy는 local opitimum에 가거나
    • slow 하게 converge 되고, high variance를 가진다.

    policy에 대하여 Deterministic policy(결정적 정책) 으로 할수도 있고 stochastic policy(확률적 정책)로 할수 있다.
    그러나 Deterministic하면 goal에 절대 도달을 하지 못하거나, 매우 오래걸린다. 보통 stochastic이 더 좋다..

    따라서, policy는 probability 이며 현재 state에서 action을 선택할 확률 이고 action들이니 확률 분포이다. \[ \pi_\theta(s,a) = \mathbb{P}[a \mid s, \theta] \]

    • Value-Based and Policy-based RL은 다음과 같은 특성을 가지고 있다.
    Method Value Function 여부 Policy 여부
    Value-Based Learnt Value Function Implicit Policy
    (e.g. \(\epsilon\) -greedy)
    Policy-Based No Value Function Learnt Policy
    Actor-Critic Learnt Value Function Learnt Policy

    Policy Objective Function #

    • policy를 최적화 하려면 \(\pi_\theta(s, a)\) 로 표현하고, 파라미터 \(\theta\) 에 대해서 best \(\theta\) 를 찾아야한다

      • 어떻게 policy \(\pi_\theta\) 를 측정하는지 세가지 방법이 있다

      • start value를 사용하는 것 \(J_1(\theta) = V^{\pi_\theta}(s_1) = \mathbb{E}_{\pi_\theta}[v_1]\)

      • average value를 사용하는 것 \(J_{avV}(\theta) = \sum_s d^{\pi_\theta}(s) V^{\pi_\theta}(s)\)

      • average reward per time-step을 사용하는 것 \(J_{avR}(\theta) = \sum_s d^{\pi_\theta}(s) \sum_a \pi_\theta(s,a) \mathcal{R}^a_s\)

      • 이것들은 결국 distrubution term이 다를뿐 같은 gradient method를 쓴다.

      • 우리는 \(J(\theta)\) 를 maximise하는 \(\theta\) 를 찾아야한다

        • gradient 을 접근할수 없을때 쓸수 있는 방법들이 있긴하다 (Hill Climbing, Simplex 기타 등등). 자세히 다루진 않음
          강의에서는 gradient에 접근이 가능하다고 보고, gredient descent에 대해서만 설명

    • 파라미터 \(\theta\) 의 델타와 목적 함수와의 관계는 다음같고. \(\alpha\) 는 batch-size \[ \Delta \theta = \alpha \nabla_\theta J(\theta) \]

    • 미분된 목적함수는 다음과 같이 표현된다. \[ \nabla_\theta J(\theta) = \begin{pmatrix} \frac{\partial J(\theta)}{\partial \theta_1} \\ \vdots \\ \frac{\partial J(\theta)}{\partial \theta_n} \end{pmatrix} \]

    Finite Difference Policy Gradient #

    • gradient ascent 를 구한다. (reward가 최대화 되어야 하므로)
    • simplelest naive approach (MC나 actor critic 대비). numarically approach
    • k개의 dimension이 있다면, \(\theta\) 에 작은 변화량 \(\epsilon\) 을 주어 (perturb 이라고 쓰네..)
      각각의 변수가(k개) objective function(목적함수)의 \(\theta\) 에 대해 미분량을 계산한다.
      • 그런데 이건 차원(k)이 무지하게 늘어나면 그만큼 미분 계산이 필요. awful compuation, and noisy
      • 그러나 심플하고 결국 correct direction을 찾아가게 된다 \[ \frac{\partial J(\theta)}{\partial \theta_k} \approx \frac{J(\theta + \epsilon u_k) - J(\theta)}{\epsilon} \]

    Monte-Carlo Policy Gradient #

    • policy gradient를 analytically 한다.
    • 우리가 gradient \(\nabla_\theta \pi_\theta(s,a)\) 를 안다고 가정한다.
    • 미분을 log미분으로 다음과 같이 변형이 가능하고 ( Likelihood Ratio Trick 이라고 하는데,, 기대값의 기울기를 계산할때 자주 쓰는 기법이래) \[ \nabla_\theta \pi_\theta(s,a) = \pi_\theta(s,a)\frac{\nabla_\theta \pi_\theta(s,a)}{\pi_\theta(s,a)} = \pi_\theta(s,a)\nabla_\theta \log \pi_\theta(s,a) \]
    • 결국 score function은 \(\nabla_\theta \log \pi_\theta(s,a)\) 다
    • 이 score function은 computation이 원본보다 easy하다

    Softmax Policy #

    • parameter 와 linear combination 으로 \(\phi(s,a)^\top \theta\) 로 나타내고
    • 이것을 exponentiate 하여 확률적으로 표현하고 \(\pi_\theta(s,a) \propto e^{\phi(s,a)^\top \theta}\)
    • 그것을 gradient 하는 계산 식에 넣어서, 기대값으로 표현하면 다음과 같다.
      • softmax이므로 이렇고, 양변에 log 취하고 양변을 미분하면 최종 식이 된다. \[ \pi_\theta(a|s) = \frac{e^{\phi(s,a)^\top \theta}} {\sum_{a'} e^{\phi(s,a')^\top \theta}} \\ \log \pi_\theta(a|s) = \phi(s,a)^\top \theta - \log \sum_{a'} e^{\phi(s,a')^\top \theta} \\ \nabla_\theta \log \pi_\theta(s,a) = \phi(s,a) - \mathbb{E}_{\pi_\theta}[\phi(s,\cdot)]\]

    직관적으로, 실제값을 다른 모든행동의 기대값 에서 뺀것이 gradient 다.

    Gaussian Policy #

    • linear combination 의 feature의 결합으로 mean을 나타냄. \(\mu(s) = \phi(s)^\top \theta\)

    • \(\sigma^2\) 도 parameterize 할수 있긴한데, 일단 심플 버전은 normal distribution일때 \( a \sim \mathcal{N}(\mu(s), \sigma^2)\)

    • 최종적으로 score function은 다음과 같이 된다. 수식적으로 몇단계 건너띄긴했는데, 생략함.. \[ \nabla_\theta \log \pi_\theta(s,a) = \frac{(a - \mu(s)) \phi(s)}{\sigma^2} \]

    • 직관적으로 즉, 평균보다 큰 행동은 확률을 늘리고, 작은 행동은 확률을 줄이는 방향으로 파라미터 \(\theta\) 가 업데이트. 결과적으로 정책은 보상 높은 행동 쪽으로 평균을 이동하게 됨.

    Policy Gradient Theorem #

    • One-step MDP를 먼저 설명하고, 이를 확장하여 Multi-step MDP에 대해 설명한다

    one-step MDP에 대해서,,

    • one-step MDP란 action을 고르고, 다음단계에 reward를 얻고 termiante 되는 MDP. 이해를 위해 가정한 MDP
    • one-step MDP의 목적함수는 다음과 같고, \(J(\theta) = \mathbb{E}_{\pi_\theta}[r] = \sum_{s \in \mathcal{S}} d(s) \sum_{a \in \mathcal{A}} \pi_\theta(s,a) \mathcal{R}_{s,a} \)
    • Likelihood Ratio Trick 을 넣으면 다음과 같다. \[ \nabla_\theta J(\theta) = \sum_{s \in \mathcal{S}} d(s) \sum_{a \in \mathcal{A}} \pi_\theta(s,a) \nabla_\theta \log \pi_\theta(s,a) \mathcal{R}_{s,a}\\ = \mathbb{E}_{\pi_\theta}[\nabla_\theta \log \pi_\theta(s,a) r] \]
    • 보상 r이 크면 정책 파라미터( \(\theta\) )를 증가시키는 것을 수식적으로 알수 있다.

    multi-step MDP에 대해서,,

    • multi-step MDP는 one-step MDP의 imemdiate reward를 value function으로 대체한것 \[ \nabla_\theta J(\theta) = \mathbb{E}_{\pi_\theta} \left[ \nabla_\theta \log \pi_\theta(s,a) \, Q^\pi(s,a) \right] \]

    결국, Policy Gradient Theorem은 다음과 같다.

    • 모든 미분가능한 policy \(\pi_\theta(s,a)\) 에 대해서,
    • 모든 목적함수, start_value를 쓰던 average reward를 쓰던, ( \(J_1\) , \(J_{avR}\) or \(\frac{1}{1-\gamma} J_{avV}\) )
    • policy graident는 multi-step MDP 수식과 같다. \( \nabla_\theta J(\theta) = \mathbb{E}_{\pi_\theta} \left[ \nabla_\theta \log \pi_\theta(s,a) \, Q^\pi(s,a) \right] \)

    REINFORCE #

    • Monte-Carlo Policy Gradient의 대표적인 구현체

    • 원래라면 \( \nabla_\theta J(\theta) = \mathbb{E}_{\pi_\theta} \left[ \nabla_\theta \log \pi_\theta(s,a) \, Q^\pi(s,a) \right] \) 를 구해야하는데, 어려우니

    • \(Q^\pi(s,a)\) 의 unbiased sample (충분히 많이 구하면 Estimated 된거랑 같음[대수의 법칙]) 를 \(v_t\) 로 씀 \[ \Delta \theta_t = \alpha \nabla_\theta \log \pi_\theta(s_t, a_t) v_t \]

    • pseudo-code

    \( \textbf{function REINFORCE} \\ \quad \text{Initialise } \theta \text{ arbitrarily} \\ \quad \textbf{for} \text{ each episode } \{s_1, a_1, r_2, \ldots, s_{T-1}, a_{T-1}, r_T\} \sim \pi_\theta \ \textbf{do} \\ \quad \quad \textbf{for } t = 1 \ \text{to } T-1 \ \textbf{do} \\ \quad \quad \quad \theta \leftarrow \theta + \alpha \nabla_\theta \log \pi_\theta(s_t, a_t) v_t \\ \quad \quad \textbf{end for} \\ \quad \textbf{end for} \\ \quad \textbf{return } \theta \\ \textbf{end function} \)

    • 직관
      각각의 샘플된 에피소드에 대해서, 전체 trajectory(출발부터 끝까지)를 본다음에, 각각의 Step에 대해서 gradient를 업데이트

    • 더 많은 iteration 이 value-based 보다 필요

    Actor-Critic Policy Gradient #

    policy-based + value-based

    • Monte-Carlo policy gradient는 high-variance 를 가지고 있음

    • value function approximator를 이용해서 Critic 모델을 구현. 하여 plug in

    • original policy gradient 는 다음과 같다 \[ \nabla_\theta J(\theta) = \mathbb{E}_{\pi_\theta} \left[ \nabla_\theta \log \pi_\theta(s,a) \, Q^\pi(s,a) \right] \]

    • 여기에서 Q-function을 다음과 같이 근사로 표현이 가능하다 \(Q_w(s,a) \approx Q^{\pi_\theta}(s,a)\)

    • 이걸 원래 수식에 넣으면 다음과 같고 \[ \nabla_\theta J(\theta) \approx \mathbb{E}_{\pi_\theta}\!\left[\,\nabla_\theta \log \pi_\theta(s,a)\; Q_w(s,a)\,\right] \]

    • 미분량은 다음과 같이 볼 수 있다. \[ \Delta \theta = \alpha\, \nabla_\theta \log \pi_\theta(s,a)\; Q_w(s,a) \]

    • 직관
      policy-model 이 actor 가 된다. action을 선택하는. value-model이 critic이 된다. 얼마나 좋을지 등을 추정해 평가해준다
      critic이 평가해준 방향으로 업데이트가 된다.

    • value function approximator 에 6장에서 배운 MC, TD, TD람다 등을 적용이 가능하다

    Action-Value Actor-Critic (QAC) #

    다음은 linear TD(0)를 approximator로 하였을때를 보여준다. Action-Value Actor-Critic (QAC)

    • action-value (q-value) 펑션을 다음과 같이 사용하고 \(Q_w(s,a) \;=\; \phi(s,a)^\top w\)
    • 전체 pseudo-code는 다음과 같다
    \( \textbf{function QAC}\\ \quad \text{Initialise } s,\ \theta\\ \quad \text{Sample } a \sim \pi_\theta(\cdot \mid s)\\ \quad \textbf{for each step do}\\ \quad \quad \text{Sample reward } r = \mathcal{R}^{a}_{s};\ \text{sample transition } s' \sim \mathcal{P}^{a}_{s}\\ \quad \quad \text{Sample action } a' \sim \pi_\theta(\cdot \mid s')\\ \quad \quad \delta \;=\; r \;+\; \gamma\, Q_w(s',a') \;-\; Q_w(s,a) \text{ // critic error calculate}\\ \quad \quad \theta \leftarrow \theta \;+\; \alpha\, \nabla_\theta \log \pi_\theta(a \mid s)\, Q_w(s,a) \text{ // actor update}\\ \quad \quad w \leftarrow w \;+\; \beta\, \delta\, \phi(s,a) \text{ // ciritic update}\\ \quad \quad a \leftarrow a',\quad s \leftarrow s'\\ \quad \textbf{end for}\\ \textbf{end function} \)

    Advantge Actor-Critic (A2C) #

    Baseline을 이용해서 variance을 줄이는 방법

    • baseline \(B(s)\) 가 있다고 하면

      • baseline은 s,a 와 영향이 없어서 밖으로 나올수 있고, \(\sum_{a\in\mathcal{A}} \pi_\theta(s,a)\) 의 sum은 1이다.
      • 남은 앞의 term은 미분이므로( \(\nabla_\theta\) ) 항상 0이 된다 \[ \begin{aligned} \mathbb{E}_{\pi_\theta}\!\left[ \nabla_\theta \log \pi_\theta(s,a)\, B(s) \right] &= \sum_{s\in\mathcal{S}} d^{\pi_\theta}(s) \sum_{a\in\mathcal{A}} \nabla_\theta \pi_\theta(s,a)\, B(s) \\ &= \sum_{s\in\mathcal{S}} d^{\pi_\theta}(s)\, B(s)\, \nabla_\theta \sum_{a\in\mathcal{A}} \pi_\theta(s,a) \\ &= 0 \end{aligned} \]

    • 좋은 baseline를 state value function을 쓰는거다. \(B(s) = V^{\pi_\theta}(s)\)

    • 그러면 우리는 q-value 와 state-value를 advantage를 쓸수 있다. \(A^{\pi_\theta}(s,a) = Q^{\pi_\theta}(s,a) - V^{\pi_\theta}(s) \)

    • 전체 수식은 다음과 같이 된다 \[ \nabla_\theta J(\theta) = \mathbb{E}_{\pi_\theta}\!\left[\,\nabla_\theta \log \pi_\theta(s,a)\; A^{\pi_\theta}(s,a)\,\right] \]

    • 직관은
      Q-value 에서 state-value 을 뺀것, 현재에서 어떤 action을 고르는게 현재 상태보다 어떤 어드벤테이지가 얼마나 있는지를 업데이트

    • 그러면 Q-value, state-value 두개를 각각 학습해야하는데, 하나만 하는 방법도 있다.

    • true value function // 가 있으면 TD error는 다음과 같이 표현된다 \[ \delta^{\pi_\theta} \;=\; r \;+\; \gamma\, V^{\pi_\theta}(s') \;-\; V^{\pi_\theta}(s) \]

    • TD error이 expectation는 결국 TD error 는 advandage function의 unbiased sample이다 \[ \begin{aligned} \mathbb{E}_{\pi_\theta}\!\big[\delta^{\pi_\theta}\mid s,a\big] &= \mathbb{E}_{\pi_\theta}\!\big[r + \gamma V^{\pi_\theta}(s') \mid s,a\big] - V^{\pi_\theta}(s) \\ &= Q^{\pi_\theta}(s,a) - V^{\pi_\theta}(s) \\ &= A^{\pi_\theta}(s,a) \end{aligned} \]

    • TD error에 대한 approximate하면 다음과 같이 표현이 된다. \[ \delta_{w} \;=\; r \;+\; \gamma\, V_{w}(s') \;-\; V_{w}(s) \]

    • 그래서 Q-value를 구하지 않고도 state-value function만으로 계산할 수 있다. 우리는 parameter w에 대해서만 구하면 된다.

    • 직관
      우리가 Q-value 가 필요한 것은 결국 advantage function을 구하기 위함인데, TD error는 A^\phi의 unbiased estimation 이므로 q-value를 구하지 않아도 된다.

    A2C의 advantage 수식을 critic에 대해서 다양한 Time-Scales를 적용하면 (MC, TD, TD람다[forwrad,backwrad])

    • Monte-Carlo \[ \Delta\theta \;=\; \alpha\,\big( v_t \;-\; V_\theta(s) \big)\,\phi(s) \]
    • TD(0) \[ \Delta\theta \;=\; \alpha\,\big( r \;+\; \gamma V(s') \;-\; V_\theta(s) \big)\,\phi(s) \]
    • forwrad-view TD 람다 \[ \Delta\theta \;=\; \alpha\,\big( v_t^{\lambda} \;-\; V_\theta(s) \big)\,\phi(s) \]
    • backward-view TD 람다 \[ \delta_t \;=\; r_{t+1} \;+\; \gamma\, V(s_{t+1}) \;-\; V(s_t) \\ e_t \;=\; \gamma \lambda\, e_{t-1} \;+\; \phi(s_t) \\ \Delta\theta \;=\; \alpha\, \delta_t\, e_t \ \]

    A2C의 advantage 수식을 actor에 대해서 다양한 Time-Scales를 적용하면 (MC, TD, TD람다[forwrad,backwrad])

    • 다음과 같은 기본식에 대해서 추가적으로 time-scales를 적용할 수 있다. \[ \nabla_\theta J(\theta) = \mathbb{E}_{\pi_\theta}\!\left[\,\nabla_\theta \log \pi_\theta(s,a)\; A^{\pi_\theta}(s,a)\,\right] \]
    • Monte-Carlo policy gradient 가 complete return error를 쓸 경우 \[ \Delta \theta \;=\; \alpha\,\big( v_t - V_w(s_t) \big)\, \nabla_\theta \log \pi_\theta(s_t, a_t) \]
    • one-step TD error를 쓸경우 \[ \Delta \theta \;=\; \alpha\,\big( r + \gamma V_w(s_{t+1}) - V_w(s_t) \big)\, \nabla_\theta \log \pi_\theta(s_t, a_t) \]

    policy gradient에 동일하게 TD 람다 적용하는 것 처럼 Eligibility Trace 할 수 있다.

    • forward이고 \[ \Delta \theta \;=\; \alpha\,\big( v_t^{\lambda} - V_{w}(s_t) \big)\, \nabla_\theta \log \pi_\theta(s_t, a_t) \]

    • forward 와 backward가 동치가 되는 점을 정리하면 다음과 같다. \[ \delta_t \;=\; r_{t+1} + \gamma\, V_{w}(s_{t+1}) - V_{w}(s_t) \\ e_{t+1} \;=\; \lambda\, e_t + \nabla_\theta \log \pi_\theta(s_t, a_t) \\ \Delta \theta \;=\; \alpha\, \delta_t\, e_t \]

    • 이것으 장점은 episode가 끝나지 않아도 online 업데이트 한다.

    • 강의에서는 natural Actor-Critic을 설명하는데, posting에서는 생략함.
