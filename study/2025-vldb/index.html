    VLDB 2025 Research Paper Sessions #

    • https://dblp.org/db/journals/pvldb/pvldb18.html 에서 Volume 18, Number 5, January 2025 ~ ?
    • 각 논문들의 abstract 만 파악하여 나열

    Detail #

    • Dandelion: Smaller Clusters, Bigger Speeds - Distributed Transactions Redefined

      • CXL, locality, key-value-store:KVS
      • 기존에는 소수의 서버에 많은 메모리를 탑재한 in-memory KVS 구축에 locality 관련 연구 미습
      • 여러 요청을 하나의 네트워크 패킷에 묶어전달하고, 배치로 전달하고, 백업 노드에 강한 일관성 로컬 읽기를 허용하는 솔루션

    • Esc: An Early-Stopping Checker for Budget-aware Index Tuning

      • index tuning, what-if query optimizer
      • 최신 예산 인식 인덱스 튜닝은 허용되는 what-if 호출 수를 제한하는 방식으로, what-if 호출이 소모될수록 속도가 느려지는 문제가 있음
      • 수익 감소 현상을 바탕으로 조기 종료하는 솔류션 제안

    • Jodes: Efficient Oblivious Join in the Distributed Setting

      • privacy, oblivious, trusted execution evironment(TEE)
      • TEE enclave 내부 연산을 은식화하는것은 상당한 오버헤드를 가짐
      • 네트워크측과 enclave측 모두 정보 유출을 방지하고, 일반적인 equi-join 연산을 지원하는, 효율적인 은닉 equi-join 알고리즘을 제안

    • OpenFGL: A Comprehensive Benchmark for Federated Graph Learning

      • federated graph learning, GNN, fair evaluation, benchmark
      • FGL들을 공정하게 평가하는 밴치마크의 부재로, 공정한 밴치마크 소개

    • Evaluating Continuous Queries with Inconsistency Annotations

      • Continuous Query:CQ, data stream, provenance
      • CQ에서 무결성을 보장하기 위해서, 일관성없는 데이터를 제거하거나, 복구하는데, throughput과 latency에 악영향
      • provenance 기반 기법을 사용하여, 오버헤드 최소화 기법 소개

    • On More Efficiently and Versatilely Querying Historical k-Cores

      • temporal graph, historical
      • historical k-core query의 최신 연구는 일부 케이스에서 모든 정점을 순회해야하는 비효율이 있음
      • core time을 기준으로 계층적 구조를 들어내는 기법 소개

    • GeoBloom: Revisiting Lightweight Models for Geographic Information Retrieval

      • bloom filter, label,
      • pre-trained language model(PLM)은 대량의 라벨된 쿼리에 의존하고 상당한 연산 자원을 요구
      • 더 적거나 라벨이 없는 쿼리만으로도 PLM 보다 뛰어난 효과성을 달성하는 경량 프레임워크를 제시

    • VerIso: Verifiable Isolation Guarantees for Database Transactions

      • Isolation Guarantees, verifcation
      • 모든 가능한 시스템 동작에 대해 폭ㄴ럽은 격리 보장을 수학적으로 엄밀,쳬게적으로 검증 도구의 부재로 제시

    • A Hybrid Approach to Integrating Deterministic and Non-deterministic Concurrency Control in Database Systems

      • concurrency, recovery, log
      • deterministic 알고리즘은 배치 실행이나 비대화형 트랜잭션 같은 엄격한 가정을 함께해서 비결정적 알고리즘과 함께 동작 어려움
      • 서로다른 동시성 제어 및 로깅 방식을 적응적으로 사용하는 하이브리드 접근 방식 소개

    • From Genesis to Maturity: Managing Knowledge Graph Ecosystems Through Life Cycles

      • Knowledge graph :KG, life cycle
      • 지식 그래프 생태계와 생애주기 개념을 제안

    • Avoiding Materialisation for Guarded Aggregate Queries

      • analytical query, aggregate query
      • 조인이 많은 쿼리의 경우 증간 결과가 폭발적으로 증가하는 방면, 최종결과는 훨씬 작아 어려운 문제
      • 논리적 물리적 수준의 최적화 기법을 제시

    • Synergetic Community Search over Large Multilayer Graphs

      • multilayer graph, cohesive
      • 멀티레이어 그래프 상의 커뮤니티 검색 문제를 다룸
      • 새로운 응집 서브 그래프 모델을 소개

    • Searching and Detecting Structurally Similar Communities in Large Heterogeneous Information Networks

      • Heterogeneous Information Networks:HINs, community model
      • 커뮤니티 마이닝 기법들은 구조적 유사성을 고려하지 않고 정점의 구체적 열할을 간과하는 문제가 있음
      • 빠른 온라인 알고리즘과 인덱스 기반 알고리즘으로 개발된 커뮤니티 모델 소개

    • Cabinet: Dynamically Weighted Consensus Made Fast

      • Conventional consensus algorithms, database
      • 기존합의 알고리즘은 과반수 노드의 합의를 기다려야하는 문제가 있음
      • 동적 가중치 합의를 이용해서 노드응답속도가 다양한 대규모 이기종 시스템에 최적 알고리즘 소개

    • Mining the Minoria: Unknown, Under-represented, and Under-performing Minority Groups

      • data mining, grouping, minority mining
      • 데이터들 중에 데표성 데이터가 부족한 경우 그룹정보를 마킹하기 어려움
      • 이중 공간으로 기하학적 변화과 초 평명 배열같은 개념을 활용하여, 대표성이 부족한 소수 집단을 빠르게 찾아내는 기법 소개

    • Efficient Concurrent Updates to Persistent Randomized Binary Search Trees

      • concurrent, query, index
      • 기존 구현체는 고속 업데이트와 멀티코어환경에서 효율적인 퀴리처리를 지원하지 못함
      • 업데이트와 쿼리 성능간의 균형을 맞추는 동시 업데이트 전략을 소개

    • Explaining Black-Box Clustering Pipelines With Cluster-Explorer

      • clustering, analyzer, explainable
      • 기존에는 클러스터에 대한 설명하기 어렵거나, 주어진 데이터 특성과 맞지 않게 클러스터링 되어있을 수 있음
      • 새로운 클러스터링 설명 도구를 제시. 98개 클러스터링 결과를 제시

    • BACH: Bridging Adjacency List and CSR Format using LSM-Trees for HGTAP Workloads

      • Hybrid Graph Transactional Analytical Processing:HGTAP, Graph-aware Real-time LSM Tree
      • 기존 디스크 기반 그래프 데이터베이스는 인접 리스트기반 트랜잭션 스토리지나, CSR(Compressed Sparse Row) 기반 분석 스토리처럼 특수 레이아웃을 요구
      • 다양한 그래프 데이터 레이아웃을 레벨별로 유용하게 수용하고 변환 할 수 있는 GR_LSM-TREE 기반 경량 멀티버전 스킴을 제시

    • FLEET: High-Performance Durable Replicated State Machines using Scattered and Coordinated Log Entries

      • replicated state machines:RSM, log, asynchronous, parallelism
      • 기존에는 순서가 부여된 로그에 대해서 병렬 처리가 어려운 문제가 있음.
      • 하이브리드 분산 로그와 비동기 순서 로그를 겹한한 고성능 내구성 RSM 프로토콜 소개

    • BigVectorBench: Heterogeneous Data Embedding and Compound Queries are Essential in Evaluating Vector Databases

      • vector database, benchmark, Embedding
      • 최첨단 벡터 데이터베이스 벤치마크는 이질적인 데이터 임베딩과 복합쿼리를 간과하여 평가함
      • 이를 위한 새로운 밴치마크 소개
