    Integration AI to DB (ML for System), second level interesting #

    • Machine Learning Inference Pipeline Execution using Pure SQL Based on Operator Fusion

      • AI4DB, ML2SQL(ML to SQL)

    • CLEAR: A Parser-Independent Disambiguation Framework for NL2SQL
