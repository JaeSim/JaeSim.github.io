    LLM 을 바닥부터 만들기 를 보고 나서 요약 #

    영상후기 #

    • LLM을 만들때는 1) 사전훈련(pretraining), 2) 미세조정(fine-tuning) 동작을 수행
    • 파인튜닝은 특별한 데이터셋이 필요함.
    • 사전 훈련된 녀석에게 내가 가진 데이터셋을 원래 사전학습에 사용했던 데이터셋 모양으로 만들어서 다시 추가 학습을 진행하는것
    • 따라서 이전에 잘하는 것이 망가질 수 있음

    느낀점 #

    • AI를 사용하는 능력 보다는 AI agent를 만드는 능력이 필요
      • detail하게는 몰라도 되지만, 자신의 도메인에 붙일 수 있는 실무 능력이 필요
      • fine-tuning 능력이 필요
